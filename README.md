# Password Strength Checker

A Python command-line tool that rates a password as Weak, Medium, or Strong and suggests how to improve it.

## What it checks
- Length (8+ and 12+ characters)
- Lowercase, uppercase, numbers, special characters
- Common passwords such as "password" and "123456"

## How to run
1. Install Python 3
2. Run: python password_checker.py
3. Type a password when asked

## What I learned
- Writing functions and scoring logic in Python
- Basics of what makes a password hard to guess
